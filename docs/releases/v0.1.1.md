# Agent X Ecosystem v0.1.1

Status: published on 2026-08-28 from commit
`6888750556cecc5277bf36b91f64a27806ea42a5`.

This is the historical record for v0.1.1. Later product and release-integrity
work is tracked in [`UNRELEASED.md`](UNRELEASED.md), not added to this release.

## What changed

- The default repository is now a clean standalone Product: Core, Benchmark,
  RAG, shared contracts, optional portable skills, and secret-free onboarding.
  Private AIOps, household, OpenClaw, Hermès, printer, and Data behavior stays
  outside the Product.
- Windows and Linux first-run commands start a loopback-only demo profile with
  internal MongoDB and Qdrant. Ollama and model downloads remain explicit and
  optional.
- Chat, Playground, Models, RAG, Benchmark, and Agent Ops now follow the same
  simple-to-expert UX doctrine and preserve visible routing authority.
- Exact-artifact profiling records model tag, manifest digest, host, context,
  and runtime identity without creating replacement tags.
- Cloud/local lane accounting and the operator campaign CLI keep local,
  free-cloud, and paid evidence separate and fail closed on identity, price,
  fixture, or receipt drift.
- The generic `learning_guide` persona and guided demo make persona discovery
  useful without embedding family identity or private prompts.
- Independent applications can use the authenticated, stateless external
  consumer v1 API, including bounded streaming and cancellation. Core does not
  take ownership of the consumer's conversations or private state.
- The optional Obsidian open-formats skill validates Markdown and JSON Canvas
  artifacts without granting vault, network, or RAG authority.

## Upgrade notes

- Environment-specific and private surfaces removed from the Product must be
  operated separately. Advanced deployments may load separately pinned trusted
  extensions only in the explicit full profile.
- The demo profile does not configure an Ollama endpoint or download a model.
  Run `ollama-doctor`, then explicitly choose native or isolated Docker Ollama.
- Read `docs/GETTING_STARTED.md`, `docs/RELEASES.md`, and
  `docs/ARCHITECTURE.md` before upgrading an existing deployment.
- Controlled deployments should consume the three v0.1.1 image digests from
  the attached `agentx-v0.1.1-images.json` manifest as one set.
